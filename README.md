本项目用于记录个人在学习算法与数据结构过程中的代码实现、思路分析以及一些理解笔记。

目前主要包含排序算法和高精度运算相关内容。

## 快速排序

快速排序（Quick Sort）是一种基于 **分治思想** 的排序算法。

基本思路是：

1. 从当前区间中选择一个基准值 `key`；
2. 通过双指针将数组划分为两个部分；
3. 左侧元素尽量满足 `<= key`；
4. 右侧元素尽量满足 `>= key`；
5. 对左右两个区间继续递归执行快速排序。

快速排序的核心在于 **区间划分**，实现时需要特别注意：

- `i`、`j` 两个指针的初始位置；
- 指针移动的时机；
- 大量重复元素的处理；
- 递归区间的边界。

平均时间复杂度：

```text
O(n log n)
```

最坏情况下时间复杂度：

```text
O(n²)
```

## 归并排序

归并排序（Merge Sort）同样是一种基于 **分治思想** 的排序算法。

与快速排序不同，归并排序是：

> 先递归划分，再进行排序合并。

基本过程是：

1. 找到当前区间的中点 `mid`；
2. 递归处理左半部分；
3. 递归处理右半部分；
4. 当区间最终只剩一个元素时开始返回；
5. 将两个已经有序的区间合并；
6. 不断向上合并，最终得到完整的有序数组。

可以简单理解为：

```text
不断拆分
    ↓
拆到单个元素
    ↓
两两合并
    ↓
得到更大的有序区间
    ↓
整个数组有序
```

归并排序的时间复杂度为：

```text
O(n log n)
```

由于合并过程中通常需要额外的临时数组，因此空间复杂度为：

```text
O(n)
```

## 高精度减法

高精度减法用于解决整数长度超过 `long long` 能够表示范围时的减法问题。

基本思路是：

1. 使用 `string` 读取两个大整数；
2. 将字符串中的每一位转换为数字；
3. 按照“数值低位存储在数组低位”的方式保存；
4. 从个位开始逐位相减；
5. 使用变量记录借位；
6. 最后删除结果中的前导 `0`。

例如：

```text
32 - 13
```

可以存储为：

```text
A = [2, 3]
B = [3, 1]
```

个位计算：

```text
2 - 3 = -1
```

个位不够减，需要向十位借 `1`，因此个位保存：

```text
-1 + 10 = 9
```

十位计算：

```text
3 - 1 - 1 = 1
```

最终结果数组为：

```text
[9, 1]
```

逆序输出得到：

```text
19
```

在实现过程中需要特别注意：

- 先判断两个高精度整数的大小；
- 如果 `A < B`，可以交换两个数并在结果前输出负号；
- 借位需要传递到下一位；
- 最终结果需要删除前导 `0`；
- 如果结果为 `0`，至少要保留一个 `0`。

核心思想可以简单概括为：

```text
逐位相减
    ↓
不够减则借位
    ↓
保存当前位
    ↓
继续处理高位
    ↓
删除前导 0
```

时间复杂度为：

```text
O(n)
```

其中 `n` 为两个大整数中较长整数的位数。
