## 快速排序

快速排序（Quick Sort）是一种基于 **分治思想** 的排序算法。

基本思路是：

1. 从当前区间中选择一个基准值 `key`；
2. 通过双指针将数组划分为两个部分；
3. 左侧元素尽量满足 `<= key`；
4. 右侧元素尽量满足 `>= key`；
5. 对左右两个区间继续递归执行快速排序。

快速排序的核心在于 **区间划分**，实现时需要特别注意：

- `i`、`j` 两个指针的初始位置；
- 指针移动的时机；
- 大量重复元素的处理；
- 递归区间的边界。

平均时间复杂度：

```text
O(n log n)
```

最坏情况下时间复杂度：

```text
O(n²)
```

## 归并排序

归并排序（Merge Sort）同样是一种基于 **分治思想** 的排序算法。

与快速排序不同，归并排序是：

> 先递归划分，再进行排序合并。

基本过程是：

1. 找到当前区间的中点 `mid`；
2. 递归处理左半部分；
3. 递归处理右半部分；
4. 当区间最终只剩一个元素时开始返回；
5. 将两个已经有序的区间合并；
6. 不断向上合并，最终得到完整的有序数组。

可以简单理解为：

```text
不断拆分
    ↓
拆到单个元素
    ↓
两两合并
    ↓
得到更大的有序区间
    ↓
整个数组有序
```

归并排序的时间复杂度为：

```text
O(n log n)
```

由于合并过程中通常需要额外的临时数组，因此空间复杂度为：

```text
O(n)
```

## 排序算法简单对比

| 算法 | 核心思想 | 平均时间复杂度 | 最坏时间复杂度 | 额外空间 |
|---|---|---:|---:|---:|
| 快速排序 | 先划分，再递归 | `O(n log n)` | `O(n²)` | 较少 |
| 归并排序 | 先递归，再合并 | `O(n log n)` | `O(n log n)` | `O(n)` |
